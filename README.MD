# Office365CLI

Command-line tools for Microsoft 365 — manage Outlook emails, SharePoint files, and Teams messages directly from your terminal.

> **🤖 AI-Generated:** This entire CLI project was generated by AI (GitHub Copilot). Every line of code, from the Graph API integration to the command-line argument parsing, was written by an AI coding agent.

## About Authentication

This CLI authenticates to Microsoft Graph using a **Microsoft First Party Application**. First party apps are registered and owned by Microsoft and are pre-consented across **any Microsoft 365 tenant** — no tenant admin consent is required, and no app registration is needed on your side.

Simply sign in with your Microsoft 365 account and start using the tools immediately.

## Quick Start

```powershell
# Send an email
outlookcli send --to user@contoso.com --subject "Hello" --body "This is a test."

# Search SharePoint files
sharepointcli search --keyword "budget"

# Send a Teams message
teamscli send-message --upn user@contoso.com --message "Hello from CLI!"
```
